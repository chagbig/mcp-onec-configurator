# Прогон инструментов mcp-configurator v1.17.0 — реестр проверки и обратная связь

## 1. Как пользоваться документом

Прогон делится на два контура. **Контур А «Чистая машина»** — установка v1.17.0
и проверка того, что работает без стендов и данных. **Контур Б «Стенд»** —
живые прогоны, где нужна тестовая база, пара cf или стенд YAXUnit.

Для каждого инструмента заполните строку: **ok** (работает), **skip**
(не было условий — укажите каких), **fail** (ошибка — приложите текст/скриншот).
Формат обратной связи — раздел 6. Замечания по v1.16 (user/password, timeout_s,
action=start/status, фокус-гвард) — раздел 5.

## 6. Формат обратной связи

Для каждого инструмента: **Инструмент → Статус (ok/skip/fail) → Что видел →
Лог/скриншот (путь)**. Логи: журнал моста `Y:\Snegopat-mcp\mcp\journal`,
work-каталоги инструментов, скриншоты `Y:\Snegopat-mcp\mcp\`. Свободные
замечания — после таблиц.

Полные описания инструментов: РУКОВОДСТВО-ПОЛЬЗОВАТЕЛЯ.docx, раздел 3
(«Инструменты (74) — по группам»); история изменений — RELEASES.md.
