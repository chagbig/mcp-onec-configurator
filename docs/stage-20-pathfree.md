# Релиз v1.2.0: путь-независимость, журнал-конфигурация, Снегопат 3.0.66 (06–08.11.2026)

Пять требований владельца → релиз v1.2.0. Коммиты: мост/сервер/установщик/доки
(см. git log с 5fdc763 до тега v1.2.0).

## 1. Путь-независимость

- Мост: `MCP_HOME` = env `MCP_SNEGOPAT_HOME` → walk-up от каталога аддина
  (`SelfScript.fullPath`) до маркера `mcp\mcp_bridge.home` → аварийно
  `C:\Snegopat-mcp`. Все пути производные. Валидационные регексы cf-путей
  (`cfg_load_cf`, `config_save`) строятся от HOME (escape через replace).
- `session_info` несёт `home`. Установщик ставит env User
  `MCP_SNEGOPAT_HOME`/`MCP_SNEGOPAT_CONFIG`.
- Сервер: `cfg.root` уже из конфига; DEFAULT_ROOT сменён на `C:\Snegopat-mcp\mcp`
  (совпадает с аварийным умолчанием моста).

## 2. Настройка журнала (46-й инструмент journal_configure)

- `<mcp>\mcp_bridge.cfg.json`: `{journal: {enabled, kinds[], maxFileMB, keepFiles}}`.
- Мост: `readBridgeCfg()` при старте + перечитывание по mtime на каждом событии —
  применение БЕЗ перезапуска конфигуратора. Ротация `<pid>.jsonl → .1.jsonl...`
  (keepFiles). kinds-фильтр (номера видов 0..6).
- Сервер: поля конфига `journal_enabled/journal_kinds/journal_max_mb/journal_keep`
  (для md_journal), инструмент пишет оба места. session_info несёт `cfg`.

## 3. Снегопат 3.0.66 (сток, без обрезки) + многоверсионность

- Архитектура та же (x64/starter.exe, addins/std/main.js — полный загрузчик).
- main.js НЕ патчится: мост включается пользовательским аддином через ключ
  `Snegopat/LoadAddins` профиля (`data\Snegopat\settings\snegopat.set`).
- **ГЛАВНАЯ ЛОВУШКА формата**: сериализат ValueTree — ОДНА строка с литеральными
  парами «\»+«n»; у дерева есть СЧЁТЧИК строк верхнего уровня
  (`{2,N,0,0,1,1,\n{1,<count>,`) — вставка листа без инкремента счётчика молча
  отбрасывается парсером (лист не грузится, ошибок нет). Плюс: арифметику срезов
  при инкременте — только через span(1) (insert вместо replace давал `{1,89,`).
  Ряд листа: `{2,<idx>,2,` лит-`\n` `{"S",loader},` лит-`\n` `{"B",0},0}`.
- `tools/make_snegopat_set.py`: `--src` (хирургическая вставка в заводской список)
  / `--fresh` (минимальный .set) / идемпотентность (лист ищется по удвоенным
  бэкслешам сериализата).
- Многоверсионность: `<дом>\snegopat\<версия>\x64\` параллельно, каждая версия со
  своим мостом в addins\mcp и своим .set; общий `<дом>\mcp` через маркер.
  Установщик принимает любой `snegopat-client-*.zip` (версия из version.json).
