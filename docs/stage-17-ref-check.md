# Этап 17. Поиск ссылок перед удалением (03–04.11.2026)

## 1. Задача

`md_delete` удалял объект без проверки ссылок; штатный поиск ссылок конфигуратора
уходит в модальное окно и не автоматизируется (ловушка этапа 13). Решение — в
XML-контуре: скан полной выгрузки конфигурации на литералы типов удаляемого объекта.

## 2. Почему выгрузка, а не cf

Первый прототип сканировал записи cf (cf_inspect) — **отрицательный результат**:
в cf-сериализациях ссылки на типы хранятся дескрипторами-uuid
(`{"Pattern",{"#",e98370a6-…}}`), литералов `cfg:CatalogRef.X` там нет; имена
встречаются только у владельца записи. Правильная среда — XML-выгрузка
(`/DumpConfigToFiles`), где ссылки выражены литералами.

## 3. Реализация

- `server/tools/ref_check.py` — сканер: литералы `cfg:<ВидСсылки>.Имя` +
  производные (Ref/Object/Selection/List/Manager) + базовый вид (`Document.X` —
  MainTable динамических списков) + русское полное имя (`Документ.X` — составы
  подсистем). `ConfigDumpInfo.xml` исключён (служебный, перечисляет своё же
  поддерево). Собственное поддерево объекта (объект + формы/макеты/модули)
  исключается **по путям** — без эвристик.
- MCP-инструмент **`md_check_refs`** (43-й): если `dump_dir` не указан — снимает
  свежую выгрузку сам: `cfg_archive_cf` (живая сессия) → temp-база (mockup_init) →
  `/DumpConfigToFiles` → temp-база удаляется, дамп остаётся в work. На 2 ГБ —
  ~25 мин; с готовым dump_dir — секунды. Ответ: refs_found, hits
  (файл:строка, литерал, контекст), truncated (останов на 100 находках).
- Юнит-тесты: ссылки вне своего поддерева находятся (реквизит чужого объекта +
  MainTable чужой формы), своё поддерево исключено, неизвестный вид — отказ,
  работа через dump_dir.

## 4. Валидация

| Проба | Результат |
|---|---|
| Негатив (малая пара): Документ.МсрТЧ43, на него никто не ссылается | ссылок нет; собственная форма исключена по пути |
| Позитив (боевая выгрузка УТ 3,3 ГБ): Справочник.Номенклатура | **НАЙДЕНЫ** — измерения регистров (`cfg:CatalogRef.Номенклатура`), 2660 файлов пройдено до лимита находок |

## 5. Ограничения v1 (сознательные)

- Права ролей и подписки на события — свой формат сериализации, не сканируются.
- Тексты запросов в модулях (`ВЫБРАТЬ … ИЗ Справочник.X`) — не структурная ссылка.
- Внешние источники/СКД-схемы с ручными именами — не сканируются.
- Инструмент **указательный**: находки требуют решения вызывающего (удаление
  запрещено НЕ блокирует — `md_delete` остаётся отдельным шагом с явным uuid).
