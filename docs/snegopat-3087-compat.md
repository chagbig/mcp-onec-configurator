## Отличия 3.0.87, требующие адаптации сервера (кандидаты v1.18)

1. **view_list глубже**: 3.0.87 возвращает контейнеры-панели (`isContainer:5`,
   пути `0`, `0/0`, `0/1`, пустые title) — серверная логика заглушки/живого
   дерева (ext_open_v2, `_focus_tree`) должна фильтровать по `isContainer`
   и/или требовать непустой title с модификатором.
2. **Карта меню версионно-зависима**: `menu_map.json` снят на 3.0.66 —
   позиционные индексы (ВНИЗ×(idx+1)) могут сместиться, если состав пунктов
   изменился. На 3.0.87 карту переснять `uia_menu_map` (UIA-скан по имени,
   версия-агностичен) — при подключённом RDP.
3. `platform_supported()` жёстко 8.3.27 → конфигурируемый список
   (проверенные: 8.3.27, 8.5.1 после живого смоука).
