# mcp-onec-configurator: агент работает в живом конфигураторе 1С

Выложил на GitHub проект, над которым работал последний месяц (Снегопат
снова стал доступен — проект ожил): **MCP-сервер, через который AI-агент
управляет живым конфигуратором 1С** — читает и правит метаданные, модули,
формы; создаёт и удаляет объекты; сравнивает конфигурации; гоняет тесты —
всё через протокол MCP, без циклов «выгрузить XML → загрузить XML».

https://github.com/chagbig/mcp-onec-configurator

## Как это работает

Мост-аддин (JScript) внедряется в конфигуратор через Снегопат и предоставляет
56 операций по файловому протоколу. Python-сервер подключается по stdio
(MCP) и транслирует вызовы агента в операции моста. Конфигуратор остаётся
живым: агент работает параллельно с человеком в том же окне.

```
Агент (Claude, GPT, любой MCP-клиент)
   │ stdio, JSON-RPC
MCP-сервер (Python)
   │ файловые запросы, по сессии конфигуратора
мост-аддин (JScript в конфигураторе, через Снегопат)
   │ SnegAPI
конфигуратор 1С
```

## Что умеет

- Метаданные: чтение всего дерева, создание/удаление/клонирование объектов,
  свойства (включая синонимы ru+en), типы реквизитов, каскадное
  переименование с переписыванием литералов в модулях;
- Модули: чтение и запись с hash-стражем (защита от параллельных правок),
  точечный patch по номерам строк, поиск по коду всей конфигурации (без
  платформы, по cf), структура модуля для навигации;
- Формы: чтение и запись XML-контуром через временную базу (2 ГБ
  конфигурация — 8–12 минут на запись формы);
- Конвейер расширений: вендор выпустил обновление + у вас доработки → одна
  команда собирает расширение (замещающие формы, реквизиты, перехватчики
  модулей, собственные объекты) и доставляет в базу линии;
- Diff конфигураций: сравнение двух cf за секунды (записный сканер) или
  полный XML-канон (кэшируется по sha1);
- Валидация: запросы через внешнее соединение, модули через платформу,
  XML-формы через lxml;
- Инфраструктура: создание/удаление инфобаз, журнал правок (кто что правил —
  человек или агент), журнал регистрации ИБ, самодиагностика установки,
  read-only пресет для сценариев «только ревью».

## Чего нет

- Отладки BSL (точки останова агент ставит, но ход отладки — интерактивный);
- Работы на Linux/macOS (конфигуратор и Снегопат — Windows-only);
- Web-интерфейса (транспорт — stdio, HTTP/SSE в планах).

## Установка

Установщик install.ps1 из поставки: кладёт мост в Снегопат, регистрирует
DynamicWrapperX, ставит Python-сервер, настраивает конфиг. Нужны только
64-битный конфигуратор 1С 8.3.27 и Python 3.11+. Подробные инструкции для
пользователя и администратора — в поставке (РУКОВОДСТВО-ПОЛЬЗОВАТЕЛЯ.md,
РУКОВОДСТВО-АДМИНИСТРАТОРА.md).

## Стек

Python (MCP SDK), JScript (мост-аддин), Снегопат (хост-аддин),
DynamicWrapperX (WinAPI для фокуса окна). 168 тестов (кроссплатформенный CI).

Лицензия Apache-2.0. Дистрибутивы Снегопата и DWX скачиваются отдельно —
ссылки в README.
