## v1.10.0 — 14.11.2026

### Renovate MVP: идея #8 конвейера идей — обновление расширений одним прогоном

- **`renovate_ext.py` (CLI-оркестратор)** — MVP идеи #8 (work, 16): конвейер
  «новый релиз вендора → адаптированное расширение + отчёт» собран из готовых

  (арбитраж спорных по top-N кандидатам) → отчёт `report.json`+`report.md`.

  attempts, last_error}` — skipped ВСЕГДА с причиной (класс #431 «молчаливые
  фолбэки»); fail-fast с фиксацией улик; build_ext/arbiter без платформы —
  skipped, не fail; arbiter rc=1 (differs) — не фейл, вердикт «спорные
  требуют человека»; cf идентичны — короткое замыкание `no_changes` (не
  тратим часы слотов). Вердикты: ok / no_changes / disputed / partial / failed.
  Инъекция шагов (run_step dict/callable) — вся логика юнит-тестируема без
  платформы. Живой прогон на реальной паре cf — на стенде владельца;

### Что умеет

**Живой конфигуратор (через мост Снегопата, платформа 8.3.27):**
- чтение дерева метаданных, объектов, модулей, форм (внутренний текст);
- журнал MetaDataEvent: кто и что правил метаданные — «human»/«agent» (md_check_refs перед удалением, md_journal);
- запись: модули (hash-страж), свойства, синонимы, типы; создание/удаление объектов;
- конфигурация: открыть/сохранить (с архивом cf-отката), синтакс-проверка, обновление БД;
- хранилище конфигурации: захват/помещение;
- формы: чтение XML из cf (`form_get_xml`), запись XML в живую базу (`form_set_xml`) —
  через temp-базу, с кэшем и верификацией (вендор цел, правки в живой форме);
- расширения: список, создание, открытие, сохранение, выгрузка cfe (см. конвейер ниже).

**Пакетные инструменты cf (без платформы):**
- `cf_inspect.py` — чтение v8-контейнера cf (2 ГБ — 6 с; сериализации, модули, формы);
- `cf_diff.py` — сравнение двух cf (XML-канон платформы; на 2 ГБ паре — ровно истинная дельта);
- `build_ext.py` — **конвейер «расширение из сравнения двух cf»**: cf1+cf2 → diff →
  заимствование → наполнение (реквизиты с маппингом префикса, Adopted-контейнеры,
  замещающие формы) → перехватчики модулей (ИзменениеИКонтроль) → cfe-артефакт +
  отчёт о непереносимых отличиях. Верификации: вендор цел (слот до/после
  расширения), CheckModules, постусловия на каждом шаге; тот же конвейер —
  MCP-инструментом `ext_build_from_cf` (этап 16);
- `mcp_to_line.py` — доставка в базу линии: правки живой базы (cf → пакетный прогон →
  постусловия XML; ~1 мин против 28 мин полной выгрузки) или готового cfe расширения
  (`--cfe --ext-name`: Load/Check/Update -Extension + постусловие хешей записей, этап 16);
- `mockup_init.py` — чистые базы-макеты из эталонного cf.
